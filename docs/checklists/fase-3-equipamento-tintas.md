## Receitas oficiais (afixar na oficina)

Preparar só 150–300 ml de cada vez.

| Uso | Mistura |
|---|---|
| Tinta plásticos / vinil | 1 : 0,7 |
| Tinta tejadilho | 1 : 1,1 a 1,2 |
| WPU501 | 1 : 1,0 (1 : 1,2 no tejadilho) |
| Verniz plásticos | 1 : 0,5 |
| Verniz tejadilho | 1 : 0,6 |

- [ ] Pressão: 22–28 psi plásticos / 18–24 psi tejadilho
- [ ] Flash off: 3–5 min plásticos / 8–10 min tejadilho
- [ ] Não montar antes de 72 h; cura 7 dias
- [ ] Não usar as pressões/diluições SEM dos resumos antigos (1,4–1,7 bar, 10–15 %)
