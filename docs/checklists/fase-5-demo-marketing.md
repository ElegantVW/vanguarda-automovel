# Checklist — Fase 5: Demonstração e marketing orgânico

**Donos:** Design (conteúdo e consistência), Oficina (demos), Atendimento (contactos e indicações).  
**Pré-requisitos:** Fase 3 com pelo menos um teste real; logótipo no Drive.  
**Fecha quando:** há prova filmável (1 viatura herói **ou** herói + peças), 10 conteúdos prontos, um canal a publicar, kit de amostras.  
**Ligações:** preços da Fase 6; farda da Fase 4 nas fotos de presença.

**Regra: zero anúncios pagos.** Sem Facebook Ads, Google Ads, boosts ou agências.

## Já feito

- [x] Instagram, Facebook e email de domínio próprio criados
- [x] Bio em suspense: «O padrão que Portugal não tinha. Em breve.»
- [x] Banners e foto de perfil (V limpo, fundo preto)
- [x] Decisão de conteúdo 100 % interno (CapCut / Canva)
- [x] Programa de indicação desenhado (10 % de desconto)
- [x] Viatura herói escolhida: Ford Focus carrinha

## Prova física

- [ ] Fechar a segunda viatura: Peugeot 106 1992 **ou** um popular (Clio / Corsa / Golf) — uma só
- [ ] Peças de teste de 2–3 carros, com sol / flexão / limpeza simulados
- [ ] Kit portátil de amostras (plástico, vinil, tejadilho) para levar a oficinas
- [ ] Guião de demo presencial (5–8 minutos: problema → processo Stardust → garantia falada → pack)
- [ ] Ford Focus: desmontagem, limpeza, mascaramento, pintura, cura 7 dias, montagem, sessão before/after
- [ ] Não filmar «after» de uma peça que ainda não curou

## Conteúdo (internamente, sem ads)

- [ ] Lista dos primeiros 10 conteúdos (reels + carrosséis)
- [ ] Incluir pelo menos: 2 before/after, 2 time-lapse de processo, 1 teste de flexão/limpeza, 1 peça de kit, 1 «quem somos» sem overclaim
- [ ] Gravar e editar os 10 **antes** de sair do modo suspense
- [ ] Frequência-alvo depois do lançamento: 5–7 posts + 4–5 reels / semana (ajustar se a equipa não aguentar — consistência > volume)
- [ ] Série «A Transformação Vanguarda»: 1 episódio / semana, só com trabalho real
- [ ] Live mensal só depois de haver uma demo que se possa mostrar
- [ ] Flyers / cartões / banner: design interno, impressão local, QR para Instagram. Sem media buyer

## Canais e parcerias

- [ ] Website simples com portfolio das viaturas / peças (atualização semanal quando houver novidade)
- [ ] Google Business Profile (ficha, não campanha paga)
- [ ] Lista de oficinas, centros de inspeção e grupos de carros (Loures / Odivelas / Lisboa norte)
- [ ] Ritmo: 8–12 contactos / semana quando o kit de amostras existir
- [ ] Meta: 6–10 parcerias ativas; comissão falada 10–15 % (Gerente fecha o número)
- [ ] Programa de indicação: texto único (10 % a quem indica / a quem vem — o Gerente escolhe um lado ou os dois)
- [ ] Oferta de lançamento falada: 15 % nos primeiros 10 serviços + peça de teste — confirmar se ainda vale quando a Fase 6 fechar preços

## O que não fazer

- [ ] Não gastar em ads «só para testar»
- [ ] Não contratar fotógrafo / influenciador / agência nesta fase
- [ ] Não publicar interior «Full Black» que ainda é peça de teste
- [ ] Não contradizer a Fase 6 com preços inventados no Instagram

## Metas aos 60 dias pós-lançamento (do transcript final)

- [ ] 8–15 serviços vendidos
- [ ] ≥ 50 % via passa-a-palavra ou parceria
- [ ] Portfolio com 2 viaturas **ou** 1 viatura + conjunto sério de peças
- [ ] Satisfação > 95 % (pedido simples no fim do serviço)
- [ ] Orçamento de apoio (site, impressos, amostras): 1.200–2.000 €, **0 € ads**

## Critério de fecho

A empresa consegue mostrar trabalho real, publicar sem mentir, e receber um cliente indicado sem ter pago um anúncio.
