# Vanguarda Automóvel

Repositório operacional da **VANGUARDA AUTOMÓVEL - UNIPESSOAL LDA**.

Serviço premium de pintura e restauro de interiores automóveis em Portugal (tecidos, vinil, plásticos e pele), com aerógrafo profissional e sistema Stardust Artistic Pro (WPU). Pintar em vez de substituir.

Este repositório é o sítio vivo dos planos, transcrições consolidadas e checklists. Não é o arquivo legal nem o baú de média.

## Como começar

1. Pedir convite de colaborador no repositório privado (GitHub).
2. Instalar [Git](https://git-scm.com/download/win).
3. Clonar:

```bash
git clone <url-do-repositorio> vanguarda-automovel
cd vanguarda-automovel
```

4. Ler pela ordem: [docs/00-indice.md](docs/00-indice.md) → [plano mestre](docs/plano/plano-mestre.md) → checklist da fase em que estás a trabalhar.
